# ArcherSec — Open-Source klonlash va tasvir yechimi

Bepul open-source klonlash, disk tasvirlarini yaratish va tiklash yechimi. PXE orqali Windows oʻrnatish, PartClone bilan tasvirlar, veb-interface orqali boshqarish.

## Imkoniyatlar

| Funksiya | Tavsif |
|----------|--------|
| PXE Boot | Tarmoq orqali yuklash |
| Disk tasviri | PartClone bilan yaratish/tiklash |
| Veb-interface | Markazlashgan boshqaruv |
| Testlar | Xotira va disk diagnostikasi |
