# ArcherSec — Свободный клонирование и имиджинг

Бесплатное open-source решение для клонирования, создания образов дисков и восстановления. Развёртывание Windows через PXE, создание образов PartClone, управление через веб-интерфейс.

## Возможности

| Функция | Описание |
|---------|-----------|
| PXE Boot | Сетевая загрузка для развёртывания |
| Образы дисков | Создание/восстановление через PartClone |
| Веб-интерфейс | Централизованное управление |
| Тесты | Диагностика памяти и дисков |
| Затирание | Безопасное удаление данных |
| Антивирус | Проверка на вирусы |
