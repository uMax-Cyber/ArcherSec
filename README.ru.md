# ArcherSec — Свободный комплекс клонирования и создания образов

Бесплатное open-source решение для клонирования, создания образов дисков и восстановления. Развёртывание Windows через PXE, создание образов дисков на базе PartClone, управление машинами через веб-интерфейс. Возможности: тестирование памяти и дисков, затирание дисков, антивирусная проверка, планировщик задач, инвентаризация, удалённая установка ПО.

## ℹ️ Архивный проект

Это ранний экспериментальный набор security- и имиджинг-инструментов на PHP, сохранённый для справки и истории. Он не поддерживается активно. Продуктовые подходы-преемники для автоматизации живут в более новых репозиториях (OpsPlaybook и другие).

## Возможности

| Функция | Описание |
|---------|-----------|
| PXE-загрузка | Сетевая загрузка для развёртывания |
| Образы дисков | Создание/восстановление образов на базе PartClone |
| Веб-интерфейс | Централизованное управление |
| Тесты железа | Диагностика памяти и дисков |
| Затирание дисков | Безопасное удаление данных |
| Антивирус | Проверка на вирусы |
| Инвентаризация | Учёт оборудования и ПО |
| Удалённая установка | Развёртывание ПО на зарегистрированных машинах |
| Планировщик задач | Запланированные задачи имиджинга и обслуживания |

## Поддерживаемые ОС
Windows XP, Vista, 7, 8, 10 (развёртывание через PXE)

## Компоненты
- `src/` — Исходный код ядра (iPXE)
- `bin/` — Установщик и бинарники
- `lib/` — Платформенные библиотеки (Arch, Red Hat, Ubuntu)
- `utils/` — Вспомогательные скрипты (бэкап, iPXE, обновление)
- `packages/` — Описания пакетов, сервисы, веб-интерфейс
- `SELinux/` — Политики безопасности

## Использование

```bash
# Установка (от root; поддерживаются Arch, Red Hat, Ubuntu)
cd bin && sudo ./installarcher.sh

# Удаление
sudo ./installarcher.sh --uninstall
```

После установки веб-интерфейс доступен из document root Apache (по умолчанию `/archer/`).
